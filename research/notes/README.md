# Weekly notes on the live bots

One file per week: `YYYY-Www.md` (for example `2026-W43.md`). Written on Friday after the close, from the ledgers
and the Actions logs, never from memory.

These notes are for finding bugs and generating hypotheses. They never change a bot's rule. A hypothesis from
the notes becomes a new pre-registration (research/prereg/) and runs as a new book on data that comes after the
notes. The original rules stay fixed until their verdict dates.

## Template

```
# Week YYYY-Www (dates)

## Bugs and operations (fixed, logged separately from method)
- what broke, the run id, the fix PR

## What went right
- bot, the trades or days, the number, the file or ledger row it came from

## What went wrong
- bot, the trades or days, the number, the file or ledger row it came from

## Open questions (hypotheses only, not findings)
- question, and what data would answer it

## Counts
- trading days so far, trades per bot, running idea count
```

Interim check at 60 trading days (exploratory, no pass or fail). Verdict at 120 trading days (pre-registered).
