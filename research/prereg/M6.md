# M6: analyst rating and price-target changes from headlines (main track)

Registered 2026-10-12, before any result of this idea was computed. Requested by Amit as a free
substitute for paid analyst data. Phase-2 count at registration: 3 (main 3). Phase 1 + phase 2 = 18.

## Question

Do the 20 stocks with the most net-positive analyst actions over the last 90 days (upgrades and
price-target raises minus downgrades and cuts, read from Benzinga headlines) beat the equal-weight
universe over the next 6 months, after costs?

## Universe, dates, costs, test

Identical to M4 (`research/prereg/M4.md`): same eligibility, entry at the next open, 6-month exit,
0.2% round trip, signal dates 2017-01-31 .. 2025-03-31 (month-ends with a full price lookback), the
2025-10-01 holdout guard, the same primary statistic, random control and pass rule (mean > 0, HAC t >=
2.0, bootstrap CI lower bound > 0). Headlines are fetched only up to 2025-09-30.

## Data

Every Benzinga article from Alpaca's news API, 2016-10-01 .. 2025-09-30 (headline, created_at,
symbols). An article counts only when it names exactly one symbol. Exact repeats of the same headline
for the same symbol within 3 days count once.

## Classifying a headline (fixed rules, case-insensitive)

- Upgrade: "upgrade", "upgrades" or "upgraded" -> +1.
- Downgrade: "downgrade", "downgrades" or "downgraded" -> -1.
- Otherwise a target raise ("raises/raised/boosts/lifts/increases ... price target" within 30
  characters, or "price target raised/increased/boosted") -> +1, and a target cut ("lowers/lowered/cuts/
  cut/reduces/trims/slashes ... price target", or "price target lowered/cut/reduced") -> -1.
- Anything else, or a headline matching both an upgrade and a downgrade, -> ignored.

The rule set is fixed now. A random sample of 50 classified headlines is printed with the result for a
hand check; a classification bug found there can be fixed and rerun (and is logged as a bug fix), a
change of the rules cannot.

## Signal (no fitted parameters)

For each stock at t: up = number of +1 headlines and down = number of -1 headlines created on or
before t (23:59 ET) and after t - 90 days. Score = (up - down) / sqrt(up + down), 0 when there are none.
The 20 highest scores are the picks (ties broken by the larger up + down, then at random with the
control's seed).

## Exploratory, decided now

Rating changes only (no targets); 30-day window; 12-month horizon; top 50; excess over SPY; per year;
coverage (share of the universe with any action).

## Stop rule

A failed screen ends M6; the result is logged and nothing on the dashboard changes.
